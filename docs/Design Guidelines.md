# DigestDesk — Design Guidelines

> 瑞士现代主义 × 报纸编辑台：克制、精确、高信息密度。

---

## 1. 设计理念

DigestDesk 的设计语言源自两个传统：

- **瑞士现代主义（Swiss Modernism）**：网格系统、字体层级、留白克制、功能至上
- **报纸编辑台（Newspaper Editorial）**：masthead、分栏排版、hairline 分隔线、目录导航

核心原则：**让内容成为主角，UI 退到最后面。**

用户每天在这个界面停留 5 分钟，不需要炫酷，需要高效、清晰、舒适。

## 2. 色彩体系

### 调色板

| 角色 | 色值 | 用途 |
|------|------|------|
| 前景色 | `oklch(0.15 0 0)` | 正文文字 |
| 次要文字 | `oklch(0.45 0 0)` | 辅助说明、标签 |
| 背景 | `oklch(0.98 0.005 80)` | 主背景，微暖白 |
| 卡片背景 | `oklch(1 0 0 / 0.8)` | 内容卡片，半透明 |
| 边框 | `oklch(0.85 0 0)` | hairline 分隔线 |
| 强调色 | `oklch(0.67 0.15 45)` | 交互元素、按钮、链接（橙色系） |
| 错误 | `oklch(0.55 0.2 25)` | 错误提示 |
| 成功 | `oklch(0.55 0.15 145)` | 成功反馈 |

### 使用原则

- 页面 90% 是黑白灰，强调色仅用于可交互元素
- 不使用渐变色、阴影堆叠
- 卡片用 1px 边框区分层级，不用 box-shadow
- 背景使用极微妙的纸张纹理（radial-gradient noise）

## 3. 字体系统

### 字体选择

| 用途 | 字体 | 备选 |
|------|------|------|
| 标题/数字 | Fraunces | Georgia, serif |
| 正文 | Newsreader | 'Noto Serif SC', serif |
| 标签/辅助 | System UI | -apple-system, sans-serif |
| 代码/数据 | JetBrains Mono | monospace |

### 字号层级

| 层级 | 大小 | 用途 |
|------|------|------|
| H1 | 2rem (32px) | 页面主标题（极少使用） |
| H2 | 1.5rem - 1.875rem | 区域标题（日报标题、页面标题） |
| H3 | 1.25rem | 卡片标题（文章标题） |
| Body | 0.875rem (14px) | 正文内容 |
| Caption | 0.75rem (12px) | 标签、时间、辅助信息 |
| Micro | 0.625rem (10px) | 极小标注（少用） |

### 排版规则

- 行高：正文 1.6-1.7，标题 1.2-1.3
- 段间距：正文用 `space-y-2`，区域间用 `gap-6`
- 标签文字统一使用 `tracking-[0.18em] uppercase text-muted-foreground text-xs`
- 中文正文不使用 letter-spacing

## 5. 组件规范

### 卡片 (Card)

- 1px 边框（`border border-border`）
- 圆角 `rounded-lg`
- 内边距 `p-4 md:p-5`
- 背景半透明（`bg-card/80 backdrop-blur`）
- 不使用 box-shadow

### 按钮 (Button)

| 类型 | 用途 | 样式 |
|------|------|------|
| Primary | 主要操作（添加订阅、生成 Digest） | 实心背景 + 白字 |
| Secondary | 次要操作（切换视图） | 浅色背景 + 深色字 + 边框 |
| Outline | 辅助操作（查看原文） | 透明背景 + 边框 |
| Ghost | 最轻量操作（删除、折叠） | 无背景无边框 |

### 分隔线 (Separator / Hairline)

- 使用 1px `border-border` 颜色
- 区域间用 `<Separator />`
- 区块底部用 CSS `hairline` class（底部边框）
- masthead 底部用 hairline

### Badge / 标签

- 用于状态指示：订阅数量、日报日期、MVP 标识
- `variant="secondary"` + `border border-border`
- 或 `variant="outline"`

### Toast 通知

- 使用 Sonner 组件
- 成功：绿色图标 + 简短文案
- 错误：红色图标 + 具体原因
- 持续 3 秒自动消失

## 6. 交互模式

### 添加订阅

首次使用（首页内联引导）：

```
新用户打开首页（无订阅源）
  → 展示 WelcomeSearch 欢迎卡片
  → 标题"集中跟踪，轻松读完"+ 搜索框
  → 用户搜索创作者名称
  → 展示搜索结果列表（Logo + 名称 + 简介）
  → 点击"订阅"
  → Toast: "已订阅，正在准备你的第一份日报…"
  → 自动触发日报生成（GeneratingProgress 四阶段动画）
  → 日报出现
```

订阅管理页（常规添加）：

```
用户粘贴 URL
  → 输入框显示 URL
  → 点击"添加"
  → [Loading] 获取 Substack 信息
  → 显示预览卡片（Logo + 名称 + 简介 + 最近文章）
  → 用户确认
  → Toast: "订阅成功"
  → 列表更新
```

### 阅读 Digest

```
用户打开 Digest 页
  → 显示今日日报（或最近一期）
  → TOC 区域列出所有文章标题
  → 点击 TOC 条目 → 平滑滚动到对应文章卡片
  → 文章卡片展示：来源、标题、一句话、3条洞察
  → 点击"Read Original" → 新标签打开原文
  → 底部"回到目录"按钮 → scrollIntoView 平滑滚回 TOC 区域
```

### 推送通知

```
浏览器通知弹出
  → "你的日报已就绪 · 2026-02-15"
  → 点击 → 跳转到对应 Digest 页面
```

## 7. 响应式设计

| 断点 | 布局调整 |
|------|----------|
| `<768px` (Mobile) | 侧边栏折叠为顶部导航；Digest 单列；TOC 折叠为下拉 |
| `768-1024px` (Tablet) | 侧边栏缩窄；两列布局保留 |
| `>1024px` (Desktop) | 完整布局，240px 侧边栏 + 内容区 |

### Mobile 优先考量

- Digest 日报是用户最常在手机上查看的内容
- 移动端 TOC 折叠为页面顶部的可展开目录
- 文章卡片全宽，间距适当增大保证可触控
- 底部导航替代侧边栏

## 10. 动效原则

- **克制使用**：仅在状态切换和反馈时使用动效
- **快速**：所有过渡动画 150-200ms
- **自然**：使用 ease-out 缓动
- **有意义**：每个动效都传达信息（加载中、成功、错误）

具体场景：
- 页面切换：无动效（即时切换）
- 卡片出现：`fade-in` 100ms
- Toast：从右侧滑入
- 按钮 hover：背景色过渡 150ms
- 骨架屏：加载时使用 shimmer 效果
- TOC 锚点跳转：`scroll-behavior: smooth`
